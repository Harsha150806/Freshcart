# 🛒 FreshCart - Online Grocery Delivery

A full-stack grocery shopping and delivery web application built with React (Vite) and Node.js (Express, MongoDB).

## 🚀 Live Deployments
- **Frontend (Vercel):** [https://freshcart-q7vh-git-main-harshas-projects-d0a52d4c.vercel.app](https://freshcart-q7vh-git-main-harshas-projects-d0a52d4c.vercel.app)
- **Backend API (Render):** [https://freshcart-1-jec2.onrender.com](https://freshcart-1-jec2.onrender.com)

## 🛠️ Tech Stack
- **Frontend:** React 19, Vite, React Router 7, Axios, React Hot Toast
- **Backend:** Node.js, Express, MongoDB (Mongoose), JWT, bcryptjs, CORS
